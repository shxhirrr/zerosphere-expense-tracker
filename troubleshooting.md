Incident Handling and Troubleshooting

Common issues handled during application support:

- Application not responding after deployment
- Service downtime due to configuration issues
- High memory usage during peak load
- Log errors indicating application failure

Troubleshooting steps followed:
1. Initial issue verification
2. Log analysis to identify root cause
3. Service restart or configuration correction
4. Validation in UAT where applicable
5. Escalation to development team for unresolved issues

Root Cause Analysis (RCA) was performed for recurring issues,
and preventive steps were documented.
