ZeroSphere – Secure Expense Tracker

This project represents a cloud-hosted application supported from an
application operations and support perspective.

The focus of this project is not feature development, but deployment,
monitoring, incident handling, and environment-based support activities
typically handled by Application Support and Managed Services teams.

Key focus areas:
- Application deployment and validation
- Environment-based support (UAT and Production)
- Monitoring and log analysis
- Incident investigation and troubleshooting
- SOP-driven operational support
