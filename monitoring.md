Monitoring and Log Analysis

Application monitoring focused on availability and basic performance checks.

Monitoring activities included:
- Reviewing application logs for errors and warnings
- Checking system resource usage such as CPU and memory
- Verifying service health after deployments or restarts
- Observing application behavior during peak usage periods

Logs were used as the primary source for identifying:
- Application startup failures
- Configuration-related errors
- Performance degradation

Monitoring findings were documented and escalated when required.
