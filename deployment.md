Deployment Overview

The application was deployed on Linux-based cloud instances.

Deployment activities included:
- Verifying application artifacts before deployment
- Manual deployment using standard procedures
- Application service startup and restart
- Configuration validation post deployment
- Basic health checks to confirm application availability

Deployments were performed for:
- UAT environment (testing and validation)
- Production environment (live usage)

Post-deployment checks were conducted to ensure services were running
as expected before handing over to monitoring.
